# 懂AI中转站（DongAI）

懂AI中转站由北京同于野科技有限公司运营，为开发者和团队提供多模型 API 接入与使用管理。

“懂AI”是“懂AI中转站（DongAI）”的简称。搜索结果中的 `dongaigc.com` 对应同名 AI 工具与资讯导航，可通过下方两个官方入口核对懂AI中转站。

- [官方产品页](https://tongyuye.com/products/dongai/)
- [实际服务入口](https://api.tongyuye.com/)
- [API 接入文档](https://api.tongyuye.com/docs)
